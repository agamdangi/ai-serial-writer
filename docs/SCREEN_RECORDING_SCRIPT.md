# Screen recording script (target: 4–5 minutes)

This is a script, **not the required video file**. Record with a screen recorder of your choice. Use a real Gemini-backed run if API access is available; never expose `.env`, API keys, or private account information. Keep the terminal font readable.

1. **Opening (15–20 sec):** show the README's quick-start and premise. Hide the `.env` file, credentials, and unrelated desktop content.
2. **Plan review (30–40 sec):** initialize the run with `python -m serial_writer init --premise-file premise.txt --run recording-demo`, then run `python -m serial_writer plan --run recording-demo` to create its 200-episode outline. Show the ten phases and a few beats in `runs/recording-demo/plan.json`. Run `python -m serial_writer arc-review --run recording-demo` to review the outline and approve it at the confirmation prompt; writing is blocked until this gate is approved.
3. **Persistent directive (60–75 sec):** run `python -m serial_writer write --run recording-demo --episodes 2`. At episode 1, choose feedback and enter: “For future episodes, Mara must corroborate every recovered signal record with a living witness before acting on it.” Show the interpreter classifying it as a directive, then approve the revised episode. On episode 2, show the resulting behavior in the draft and the saved directive with `python -m serial_writer directive-list --run recording-demo`.
4. **Forward arc change (60–75 sec):** at episode 2's review prompt, choose feedback again and enter: “Change the next story window: reveal that the missing passengers are alive on the erased line, and make rescue conflict with exposing the Authority.” Confirm that the response is classified as a plan change and show the affected beats being replanned before approving the episode. If it is classified differently, clarify the request rather than claiming a replan occurred.
5. **Resume and observability (35–50 sec):** quit at the next review prompt, run `python -m serial_writer resume --run recording-demo`, and show that it resumes at the next unapproved episode. Briefly show relevant decisions in `trace.jsonl` and the estimate from `python -m serial_writer estimate --run recording-demo --target-episodes 200`.

Before sharing, inspect the recording for secrets and confirm it is under five minutes. Rehearse with the fake demo if useful, but record the interactive live CLI for the deliverable; label any fake-provider footage as synthetic. Keep the clip focused—do not spend recording time installing dependencies or entering credentials.
